Damage Efficiency — bar tuner

Axis = damage across the four mark requirements, in four visually equal quarters. Dark theme only: a light one would corrupt colour judgement on a tool for picking HUD colours.

Emitted CSS ends with a JSON block of the axis, the band colours, the timings and the cap-clamp corridor — phase 2's JS needs the numbers, not just the CSS. Numerals here are the real bundled MoEBattle.ttf, inlined — so the two baseline nudges are the metric the game will actually use, not an approximation, and they need no in-game re-check. Its 19-glyph subset is digits plus % ( ) + - , . / and space: no letters (hence panel chrome in a system font) and no thin space, so the thousands separator is a knob, comma by default. Glyphs are 48px data: cuts (img:// is dead in a browser) and the emit carries the real img:// urls with the 128px art's measured bboxes.
